# 大鱼吃小鱼（Fish Evolution）游戏设计文档

# 一、项目概述

项目名称：

Fish Evolution

类型：

2D
休闲成长
吞噬进化
单机

目标平台：

* Android
* iOS
* Windows

核心玩法：

玩家操控鱼类在海洋中生存。

通过吞噬比自己小的生物成长。

最终成为海洋霸主。
